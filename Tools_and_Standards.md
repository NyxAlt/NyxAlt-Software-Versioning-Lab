# Software Development Tools and Standards

## Development Tools & Purpose
* **Git:** Distributed version control system used to track changes in source code.
* **Visual Studio Code:** Extensible source-code editor for writing, debugging, and building applications.
* **GitHub:** Cloud-based hosting service for Git repositories providing collaboration features like Pull Requests and Issue Tracking.
* **GCC / Clang:** Compilers used to transform C/C++ source code into executable binary files.
* **GDB:** Debugging tool used to inspect and step through software executions to resolve bugs.

## Coding Standards & Best Practices
1. **Consistent Naming Conventions:** Use clear casing strategies across variables and functions.
2. **Proper Indentation and Code Formatting:** Maintain consistent tab spacing to ensure code readability.
3. **Comprehensive In-Line Documentation:** Include concise comments explaining non-obvious logic and function headers.
